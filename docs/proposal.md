ChipsvsCrackerZ : Byte-sized firmware, deep-fried electronics.
ChipsVsCrackerZ is a Capture The Flag platform for embedded devices and electronic circuits. Players can play and solve hardware security challenges using simulated chips and components. Authors can create challenges using the lab editor.
Register – allows users to create an account.
Login – allows registered users to access the application.
Dashboard – displays relevant information and activities.
Profile – allows users to view and manage their profile.
Logout – allows users to securely exit their account.
Labs List – Displays the library of available firmware CTF labs categorized by difficulty, allowing users to browse and select challenges.
Lab – embeds a Wokwi-powered virtual hardware canvas and a code editor directly in the browser, allowing users to run, test, and debug firmware in real time.
Flag Submission & Validation Engine –  provides an input form where users can submit flags to automatically verify solutions, update their completion status, and record scores.
